# NVE-inspired 有界残差匹配

来源：[Beyond Normal References v2](https://arxiv.org/html/2605.23231v2)，2026-05-30。已核对 §4.1–4.4、表3、附录D。NVE 来自该论文，不是本轮原创。

| 论文位置 | 本轮对应与边界 |
|---|---|
| 式(1) | L2映射特征 x 减去同一个有界正常库中最近正常向量；不是减邻居均值 |
| 式(2) | 每个故障向量和每个查询patch各检索12个正常patch；同分稳定按原库索引；12不是独立正常图数 |
| 式(3) | 对该向量自己的12邻居中心化，以薄SVD得到最多4个右奇异方向；不构造covariance |
| 式(4) | r_clean=r-alpha*U*(U^T*r)，B alpha=0，C alpha=.8；两侧都处理 |
| §4.2 式(5)–(7) | 完整IDEAL包含训练过的IDE及异常参考mask。本轮不使用两项，也不训练骨干或mapper |
| §4.3 式(8)–(9) | 本轮以固定容量残差库的最近邻余弦匹配代替IDE投影，.5*(dN+max residual cosine)是明确工程改造，非式(9)完整复现 |
| 图像聚合 | 本轮保持历史40×40全部patch完整评分后top8均值；不改为论文top1% |
| §4.4 | 不进行episodic训练、分割损失、BCE或IDE损失训练 |

表3将直接双参照匹配、NVE匹配、原始残差加IDE及完整模型区分；附录D考察其他残差方法替换为NVE残差。它们提供消融动机，不证明本轮特征和监督条件必然受益。

A=max_f cos(q,f)-max_n cos(q,n)。B/C=.5*[1-max_n cos(q,n)+max_f cos_eps(r_alpha(q),r_alpha(f))]。
cos_eps用max(norm,1e-8)作分母，零向量相似度0。不丢弃小残差，不截断负分，不将分数称为概率，不做逐图min-max。

正式映射、库、评分、SVD全部FP32；关闭matmul TF32，正常图骨干提取保持历史cudnn.allow_tf32=True。环境固定历史系统Python、torch2.8.0+cu128。薄SVD固定CUDA gesvdj（将12×128中心化邻居转置为128×12，取左奇异向量，即原矩阵右奇异向量）。相对阈值1e-6，r_eff=min(4,rank)；零秩不消除。SVD分块2048个patch，图像batch初始及计划值32，不按成绩改精度。B/C共享残差与投影实现，仅alpha不同。

直接读取历史SUPPORT_LISTS，不重新抽样。N/F每配置建一次，容量各<=256；F仍由该预算N按历史P1与FPS构造。查询和故障支持用现有P3缓存。39张正常参照没有现成路径缓存，仅按历史单图前向及FP16原始特征存储惯例提取一次，随后转FP32映射；所有映射特征按路径缓存复用。骨干、mapper均eval/no_grad，状态（含BN buffers）SHA256前后核验。

统计用平均秩AUROC，包括常数分0.5；按参照组先平均3种子，再给5组均值、范围、std(ddof=0)、正收益组数，另报15配置负收益数。PatchCore只复用原分数并逐路径核对：1N1A比1N，5N5A比10N。两个预算查询不同，不能解释为纯shot效应；参照重叠、查询共享，不能作独立显著性推断。

预注册可视化：每资产/预算取按完整路径排序的前2正常、前2故障图，固定seed0/ref3001。A/B/C热图统一固定[-1,1]色标，残差范数统一[0,2]；展示40×40原生网格，图像resize仅用于对照，无自动挑选失败案例。机制统计按正常图/故障图标签分层，故障图中的patch不等于故障patch；无故障像素保留率。
