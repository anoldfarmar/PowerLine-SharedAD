## 4. 五问回答

1. **C 负结果仍成立**: C 与 C2 均处随机水平; 机制证据 = 两视图对应余弦 0.987 (任务平凡满足) + 满秩均匀但判别无关的表示.
2. **多余前向/BN 影响有多大**: 机理确凿 (15840 vs 5280 次统计更新), 量化影响小 (统计差 ~1-2%, AUROC 差 ±0.02 内符号混合).
3. **已排除**: 常数输出、BN 统计异常、BN 错配为 C 失败主因、管线/指标异常 (A 复现历史). **新发现**: B 有效秩 6.4 仍最佳. **仍未知**: C 失败完整归因 (同增强控制未做)、B 塌缩与性能的因果、跨包源帧独立性.
4. **是否干净重训 C**: 本轮证据下边际信息低 (BN 敏感性已量化, 重训回答的是流程一致性); m3diag2_train.py 已备好, 是否执行由人类裁决.
5. **是否转向原型选择诊断**: 建议转向, P0/P1 已按裁决备好 (严格隔离主方案, 每资产固定 10 张, 固定 mapper_B; glass 21/yoke 2964 可行, 其余缺口已记录). B 的低秩近共线结构 (跨框余弦 0.877) 意味着库内原型高度冗余, 与原型选择假设相关 (观察性联系, 不构成结果预判).
