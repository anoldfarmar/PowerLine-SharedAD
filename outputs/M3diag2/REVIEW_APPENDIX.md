## A. 多余前向 (确认存在, 影响不可解释为零)

`scripts/m3diag_train.py` 逐行核实:
- **L69** `z = head(xb.view(-1, CH))` 在 B/C 分支之前执行;
- **L70-77** B 分支使用 z (正常);
- **L79-80** C 分支另做两次增强视图前向 z1/z2, z 未参与 C 的损失图 (loss.backward 不回传到 z)。

**但不能解释为无影响** —— head 在训练模式下, 每次前向都会更新 BatchNorm running statistics:
- C 每步 3 次 train 模式前向: raw (L69) + view1 (L79) + view2 (L80);
- momentum=0.1 下每步: s <- 0.729·s + 0.081·b_raw + 0.09·b_v1 + 0.09·b_v2;
- **稳态构成: raw 约 30%, 增强视图约 70%**;
- 推理 (bank_eval) 在 eval 模式用 running stats 归一化**未增强**特征 -> C 的 BN 统计与推理分布错配;
- B 每步仅 1 次前向 (100% raw), 无此错配 -> **C-B 对比混入了 BN 统计分布差异这一混杂变量**;
- z 持有计算图至 step 结束 (显存浪费), 但无梯度功能影响。

**修正** (m3diag2_train.py): 原始特征前向移入 B 分支; C 仅做双视图前向。
不用 no_grad 包裹来修复: no_grad 不阻止 train 模式下 BN running 统计更新 (本附录 A 即该机理)。

## C. B 与历史 metric-v1 的关系: 机制复现, 非严格复现

| 项 | 历史 m3_metric_train.py | m3diag_train.py (B) | 判定 |
|---|---|---|---|
| 损失函数 | SupCon temp 0.07, 框级标签广播 | 同 (逐行复制) | 机制一致 |
| 映射器/初始化 | Linear-BN-ReLU-Linear, manual_seed(0) 后构建 | 同 | 机制一致 |
| 梯度裁剪 | **无** (grep 全文无 clip_grad) | **L87 clip_grad_norm_ 5.0** | 差异 |
| 采样器 | 类均衡 randperm, 种子消费序列不同实现 | 同机制不同实现 | 序列不同 |
| 指标 | 序数秩 auroc_recall | 平均秩 auroc_avg_rank | 差异 (已声明) |
| 特征缓存 | 同一提取管线 | 200 样本对拍 max_abs_diff=0.0 | 一致 |

结论: B 为**机制等价重训**; 与历史汇总 (0.618/0.612/0.603 vs 0.574/0.598/0.558) 的差异由裁剪/采样序列/指标实现共同构成, **无控制实验不得归因于单一改动**。
