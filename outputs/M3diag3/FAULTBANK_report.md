# M3DIAG3 故障原型筛选诊断报告 (P0 / P-random / P1)

> 任务: M3DIAG3-faultbank-p0p1-v1 · 日期: 2026-09-21 · 合同: 草案 v3 (人类授权后按 M3DIAG2 先例以草案路径激活)
> 固定: mapper_B / P3 特征 / 冻结划分 / coreset(256, FPS seed 0) / top-8 最大余弦 / 平均秩 AUROC
> 边界: 探索性诊断 (查询集复用); 严格隔离仅针对新增正常参照, 骨干与映射器仍继承历史源帧重叠边界

## 1. 结论摘要

- **k10 处 P1 获得一致支持**: 两资产同时对 P0 与 P-random 占优, 且 P1-P-random 在两资产均为 3/3 种子为正 (glass +0.053, yoke +0.171);
- **k1/k5 未获一致支持**: 配对差符号混合、幅度与种子噪声同量级;
- **随机筛选本身有害**: P-random-P0 在 k10 两资产均为负 (-0.015/-0.055), 即随机砍半候选会伤害性能, 而 P1 的正常距离排序抵消并反超了这一损失;
- 3 支持种子不构成显著性检验; 正常参照仅抽取一组, 不估计抽样方差 (限制见 §6)。

## 4. 七问回答

1. **P1 是否高于 P0?** 仅 k10 成立且两资产一致 (+0.039/+0.116); k1/k5 差异在噪声内。
2. **P1 是否同时高于 P-random?** k10 成立 (两资产, 各 3/3 种子); k5 仅 yoke 弱正; k1 混合。
3. **两资产方向是否一致?** k10 一致; k1/k5 不一致。
4. **改善是否跨支持种子?** k10 的 P1-P-random 跨全部种子 (两资产 6/6); P1-P0 为 5/6。
5. **是否存在正常覆盖不足/背景筛选/来源失衡?** 诊断: 三臂库内最近邻余弦均 ~0.95 (库高度冗余, 与 B 有效秩 6.4 一致); 原型来源图 = 全部可用支持图 (无失衡); 边缘占比三臂相近 (0.47-0.55, 筛选未特异推向边缘或背景); P1 保留候选的正常距离 (0.041-0.047) 高于被排除 (0.028-0.035), 筛选规则按设计起效但分离度有限。
6. **新增预算换来的收益?** 成本 = 每资产 10 张正常裁剪 + 一次距离计算; 收益集中在 k10 (宏 +0.077 vs P0); k1/k5 无可见收益。
7. **下一步?** 当前证据支持"值得在 k10 检验正常参照抽样稳定性" (仅一组抽取是本轮最薄弱点), 而非停止筛选方案; 是否执行由人工门裁决。注意 k5 的回落未获解释, 抽样稳定性实验应同时覆盖 k5。

## 5. 观察与解释的区分 (简报二.3)

- 高有效秩不等于故障可分 (C 满秩仍随机); 本报告未以有效秩推断库质量, 而是实测库内最近邻余弦;
- 高对应余弦 (M3DIAG2 的 0.987) 是任务平凡满足的**证据之一**, 不单独证明;
- 低有效秩/高平均余弦不直接证明原型库冗余 —— 本轮以 nn 余弦 0.95 直接记录冗余现象;
- BN 重校准 (M3DIAG2) 不是删除多余前向的严格因果实验;
- 正常距离更高是筛选规则的直接结果, 不构成"选到了故障"的证据; 无像素真值, 可视化仅观察, 不声称定位准确;
- 有效秩口径确认: M3DIAG2 repr_diag 的协方差基于**归一化前**特征 (pre-norm), post-L2 逐维 std 另行报告。

## 6. 限制

- 3 支持种子, 无显著性检验; 同源帧多裁剪不作独立观测;
- 正常参照仅一组 10 张/资产, 抽样方差未估计;
- 探索性: 查询集已参与研究决策;
- 其余三资产缺口如实记录 (lightning 1 / pius 2 / vari-grip 0, 见 normal_ref.json), 本轮未纳入;
- P1-disclosed 未运行。
