## 1. 结论摘要 (负结果, 如实登记)

**在相同骨干/支持样本/原型预算/评分方式下, 局部对应训练 (C) 未优于资产标签 SupCon (B), 也未优于固定随机投影 (A)。**

- C 的 mean-over-combos AUROC = 0.484-0.504 (k1/k5/k10), 处于随机水平;
- 配对差 C-B: 21 个 (组合×k) 单元中 19 个为负, 均值约 -0.10;
- B (SupCon 复现) 是三者最佳 (0.558-0.598), B-A 在 15/21 单元为正;
- A (固定映射) 独立复现了历史 P3-patch-pre (0.476/0.516/0.499 → 0.4757/0.5162/0.4992), 验证了评测管线。

## 3. 五问回答

1. **局部对应训练是否优于现有 SupCon? 否 (本轮)。** C 全面接近随机水平; 该判断在冻结协议与多重正确性检查下成立。
2. **收益是否跨多个故障组合存在? 不存在。** 无任何组合×k 显示稳定为正的 C-B 差值; 唯一正例是弱统计组合。
3. **能否排除塌缩、指标异常和数据重叠解释?**
   - 塌缩: 排除。C 末 epoch 方差项 = 0.0008 (std≥1 目标满足), smoke 检查投影输出维度 std 中位 0.49, 无 constant_score 标记;
   - 指标异常: 排除。平均秩 AUROC + NaN/常数分检查全 ok; A 变体独立复现历史 P3-patch-pre 至小数点后三位;
   - 数据重叠: 不解释 C-B 差异。继承重叠 (M2 既定边界) 对三变体同等作用; path 级支持∩查询 = 0; 源帧级重叠逐配置登记 (最大 6 帧/组合)。
4. **哪些观察支持粗标签假设, 哪些不支持?**
   - **不支持**: 资产标签 SupCon 损害局部判别的怀疑未获证实, 同预算下 B 显著优于不使用资产标签的 C 与 A; 粗标签信号是三个变体中唯一携带缺陷相关信息的监督源;
   - **部分支持**: B 的增益在结构性组合大、纹理组合小, 说明粗标签的判别力集中在形状/结构维度, 与粗标签难以监督纹理级差异的方向一致, 但这是增益幅度问题而非有害证据;
   - **关键设计教训**: C 的对应任务被平凡满足 (同几何坐标 + 轻度扰动使 invariance 降至 0.020), 对应学习没有产生超出随机投影的判别结构; 负结果可能反映任务太容易/信号与缺陷无关, 而非对应学习本身劣于 SupCon。
5. **下一步是否值得做同增强控制或多层融合?**
   - 同增强控制 (B+双视图): 优先级降低, C≈A 表明双视图机制本身在当前设计下没有增益;
   - 对应学习路线若继续, 需要非平凡对应目标 (如位置/相对位置辅助任务), 属新提案交人类裁决;
   - 多层融合/特征源升级: M3 瓶颈结论 + 本轮 B 天花板 ~0.60 仍支持该方向, 由 M3DIAG 人工门裁决。
