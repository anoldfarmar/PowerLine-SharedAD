## 3. 口径的两侧偏差 (如实披露)

- **过排除方向 (安全)**: DJI 号跨航次重号严重 (7,935 张训练图仅 876 个唯一号, 平均 ~9 图/号)。不同会话的同号帧被并为一组 → 池被过度收缩。这只会让"干净残余"更少, 不会虚报独立性;
- **漏检方向 (不可验证)**: 若某 FD 帧的 det 副本被改名丢掉 DJI 号, DJI 匹配会漏检。无证据表明存在此情形 (det 全部图像名含 DJI 号), 但无法穷证;
- 图像相似度只能**确证正关联** (裁剪 ⊂ 原帧), 不能证明"不存在同源关系" (缩放/裁剪使负匹配不可靠) —— 按简报仅作辅助, 本审计未依赖它;
- 杆塔级分组信息在裁剪包中不存在, 无法报告组级交叉; 航次级: det 212 航次 vs FD 35 会话, 无桥接。

## 4. 分支判定: **C —— 独立故障源帧不足, 停止确认性实验**

在唯一可辩护的口径下, 两个资产的故障源帧 **100%** 位于检测骨干训练集 (且 100% 位于冻结评测池, 即已参与研究决策); unAD 官方 test 划分亦无例外。**不存在可同时容纳 10-shot 支持、10 张正常参照与测试集的未用源帧, 一个都没有。**

按简报三分支: 不满足 A (无干净数据); B 的前提 (从现有训练数据重新划分) 仅能实现"源帧隔离重评"——且由于故障帧 100% 在冻结池中, 重评所用测试帧**全部参与过 M2-M4 的研究决策**, 不冒充完全未见数据的确认性检验; C 成立。

不静默降低隔离标准, 不以"disclosed"沿用独立测试标题。

## 5. 若人类仍要推进: B 路线 (源帧隔离重评) 成本草案

前提: 新划分 (按 (会话,DJI) 留出测试帧) + **重训检测骨干与映射器** (不得复用见过测试帧的 best.pt/mapper_B 宣称独立):
1. YOLOv8n 重训 (60ep, imgsz1280): ~2-3 GPU h;
2. 特征重提取 (全评测裁剪): ~0.5 GPU h;
3. mapper_B 重训 (5,280 步): ~0.3 GPU h;
4. 三臂 k10 评测 + 报告: ~0.3 GPU h;
合计 ≈ **3.5-4.5 GPU h** + 协议重设计 (新划分冻结、对照重定义)。
必须随附披露: 测试帧曾参与探索期研究决策; 结果标题为"源帧隔离重评", 非确认性检验。

## 6. 最终判断

- 当前数据条件下, **对 P1 收益的独立确认不可实现** (Branch C);
- M3DIAG3/4 的结论维持探索性表述: "k10 两资产、对随机筛选一致占优; 对 P0 在 yoke 稳定、glass 敏感; k5 无收益";
- 人类可选: (i) 接受探索性结论存档, 停止筛选路线; (ii) 批准 B 路线源帧隔离重评 (~4 GPU h, 带上述披露); (iii) 引入真正未见的新的源数据 (超出当前数据边界, 需另行立项)。
