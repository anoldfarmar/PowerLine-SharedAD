# 硕士论文研究方案（v1.1）
## 有界原型记忆的少样本电力部件故障检测：兼得少样本能力与 RK3588 端侧可部署性

> 生成方式：deep-research 技能 · Socratic 模式收敛（v1.0）+ 申请人范式批判修订（v1.1）
> **v1.1 变更**：采纳申请人"范式错位"批判——废弃 k-shot 跨范式正面对比；架构从"半监督检测器+异常筛选"重构为"**原型头检测器**"；FiLo/AnomalyCLIP 降为文献参照；跨域章保留但减负（原型扩展式）
> 状态：候选方案 · Week-1 数据核查与定向 lit-review 后出 v1.2

## 0. 一句话方案

提出**原型头少样本检测框架**：轻量可量化主干 + 非参数原型分类头，使"新增故障类 = 向有界记忆添加原型（不重训）"——少样本能力来自有界记忆、可部署性来自小主干，从而在**单模型层面**回应"少样本与边缘部署互斥"这一领域张力；在 InsPLAD-FD 上以**范式内对齐协议**与 PatchCore/PaDiM/EfficientAD 互比，以范式间"标注预算-召回前沿"分析图收束。

## 1. 核心张力与科学问题

**领域张力（本论文的立论）**：当前少样本/零样本故障检测的性能记录由"预训练大表征 + 非参数记忆"方法保持（PatchCore 记忆库、FiLo/AnomalyCLIP 的 CLIP 级主干——见 [arXiv 2310.18998](https://arxiv.org/abs/2310.18998)），但这类方法无法部署到 6 TOPS 级 NPU；可部署的轻量检测器（YOLO 系）依赖标注训练，k<10 时失效。**少样本能力与端侧可部署性在现有文献中呈互斥分布**。

> **RQ：能否构建一个检测框架，使其少样本能力（k-shot 加类不重训）与 RK3588 端侧可部署性同时成立？其性能-代价边界在哪里？**

- **RQ1**：非参数原型头在 1/5/10-shot 下能否达到记忆库式 AD 的故障类召回，同时端侧延迟低 1-2 个数量级？
- **RQ2**：面向稀缺故障类的原型构建与度量学习训练策略中，哪些组件贡献了增益（消融可证伪）？
- **RQ3**：INT8 量化对原型相似度判别的影响有多大，蒸馏/量化感知训练能回收多少？

**范式批判存档（申请人贡献，v1.1 起点）**：参数化检测器（YOLO+半监督）与非参数化少样本 AD 在同一 k 轴上正面对比是范式错位——前者 k<10 无种子模型、伪标签机制失效；后者少样本能力来自"预训练表征+记忆"而非训练。本方案所有对比协议据此重排（§5）。

## 2. 架构：原型头检测器（B 方案，申请人选定）

```
输入图像(切片推理/SAHI 处理小目标)
   │
轻量主干(预训练, 标准卷积, INT8 友好)  ← 可部署性来源
   │  多尺度特征 (P3 为主, 小目标)
   ├──────────────┐
   │              │
原型相似度分类头      框回归头(常规轻量)
(非参数: 与每类原型   (在基类资产标注上训练)
 余弦相似度打分)      │
   │              │
   └──────┬───────┘
      NMS → 检测框输出 (端到端, 有类别)
      
少样本加类 = 新故障类 k 个实例 → 特征聚合为原型 → 入库
(记忆有界: 每类 10~100 向量 × 128d → KB 级, NPU/CPU 均可)
```

**与 PatchCore 的本质区别**：PatchCore 的记忆库是**全图 patch 级**大库（kNN 带宽瓶颈，anomalib 社区已知痛点）；本方案的记忆是**类级原型小库**（每类十几个向量），把"非参数少样本"与"有界推理成本"同时保住。

**分级实现策略（对"能改不能造"的制度化解药）**：
- **v0（M2-M3）**：冻结预训练主干 + 余弦原型头 + 最简度量损失（拉类内/推类间）——改 ultralytics/MMDetection 的 head 模块，不碰训练循环；
- **v1（M3-M5）**：+基类度量学习训练、极不均衡采样、框头联合微调；
- **v2（仅当时间富余，P2）**：episodic k-shot 元训练。
- **降级预案**：若端到端原型头效果不佳 → 退回"**部件裁剪级原型分类**"（先用基类检测器出部件框，再对裁剪区域做原型分类）——这恰与 InsPLAD-FD 的部件级协议天然对齐，且实现更简单，保底可毕业。

## 4. 创新点（v1.1 重排）

### 创新点一（算法·结构）：有界原型记忆的少样本检测头
非参数原型分类头 + 轻量可量化主干；新增故障类零重训；记忆 KB 级有界。
**可证伪假设 H1**：1/5/10-shot 下，故障类部件级召回不低于 PatchCore/PaDiM（同协议差距 ≤2 点），且推理延迟较部署版 PatchCore 低 ≥5×、与 EfficientAD 同数量级，同时输出类别化检测框（AD 基线做不到）。

### 创新点二（算法·训练配方）：稀缺故障类的原型构建与不均衡度量学习
基类度量学习 + 故障类 k-shot 原型聚合策略（聚合方式×原型数×背景原型抑制）+ 极不均衡采样。**可证伪假设 H2**：原型构建策略各组件带来可分离的召回增益（消融轴即证据）。

### 落地验证章：INT8 原型量化保真（RK3588）
PTQ INT8 → 相似度头量化保真逐类分析（重点：故障类召回损失）→ 超阈值则蒸馏/QAT（P1）。板级三项实测（mAP、FPS、内存）。**跨域减负实验并入本章或独立小节**：冻结主干 + STN-PLAD 原型扩展。
